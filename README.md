# Firefighter Linux 0.1 Basic

This repository branch contains the basic visual files for the first Firefighter Linux 0.1 ISO test.

## Included

- Welcome screen files
- Welcome screen screenshots
- Basic GRUB branding files
- Basic login screen branding files

## ISO Goal

Firefighter Linux 0.1 will be a simple Xubuntu-based test ISO prepared with Cubic.

This version is focused only on basic appearance and first boot testing.
