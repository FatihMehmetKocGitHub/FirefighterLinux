# Firefighter Linux Project Structure

## branding
GRUB, Plymouth, wallpaper, login screen and OS identity files.

## calamares
Installer configuration files.

## docs
Project documentation, screenshots and release notes.

## gui
Firefighter Linux graphical applications.

## installer
Installation helper scripts.

## iso-tools
ISO build scripts and release tools.

## lora
LoRa and radio-related tools.

## mesh
Meshtastic and mesh communication tools.

## maps
Offline map system, tiles, markers and related tools.

## reports
Offline report examples and templates.

## scripts
Firefighter Linux command line tools.

## server
Central server infrastructure.

## server/api
Firefighter Linux central API.

## server/database
PostgreSQL schema and migrations.

## server/lxc
LXC/LXD container setup scripts.

## server/nginx
Reverse proxy and web server configuration.

## server/repo
APT repository and package update infrastructure.

## config
Example configuration files.

## packages
Debian package build files.

## tests
Test files and validation scripts.
